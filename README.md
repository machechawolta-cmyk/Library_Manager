# Library Manager (BIWA2110)

React (Vite) frontend + Express backend + MySQL.

## Setup
1. **Database:** run `backend/schema.sql` in MySQL (Workbench or `mysql -u root -p < backend/schema.sql`).
2. **Backend:** edit DB password if needed (env `DB_PASSWORD`), then
   `cd backend && npm install && npm start` (http://localhost:5000)
3. **Frontend:** `cd frontend && npm install && npm run dev` (http://localhost:5173)

## Logins
- Admin: `ADMIN001` / `admin123`
- Member: `MEM001` / `1234`

## Features
Dashboard with low-stock highlight (<2), book CRUD, add/borrow stock with history, login + admin user CRUD.
